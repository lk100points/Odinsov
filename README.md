# 🚗❄️ Заезд в Одинцово
Бесконечная ночная аркадная гонка-выживание в зимнем лесу: ретро-3D (320×180, пиксельный стиль конца 90-х), вид от первого и третьего лица, дробовик под козырьком, дрифт, боты-«подрезалы», магазин скинов/шин/дробовиков/следов и прокачка. Играть: открой `index.html` (мобильный горизонтальный экран) или включи GitHub Pages.
**Управление:** ◀ ▶ руль, ГАЗ/ТОРМОЗ, ВИД — смена камеры, R — перезарядка. Клавиатура: стрелки/WASD, C, G, пробел/клик, R.
В виде от первого лица тапни по дробовику вверху справа — возьмёшь его на ходу; тап по экрану — выстрел. Очки = валюта. Разбился — машина испарилась матричным кодом.
